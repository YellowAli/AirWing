# Airwing Application  

A comprehensive flight management solution that streamlines scheduling, ensures safety, and minimizes human errors.  

---

## Overview
The Airwing Application is a local flight management system designed to simplify the creation and management of flight schedules. It combines the power of SQL, server-based databases, and APIs with a user-friendly interface built using JavaFX. The application prioritizes efficiency, safety, and flexibility, providing a seamless solution for managing flights without overlaps or conflicts.  

---

## Features  
- Flight Scheduling & Validation 
  - Automates the scheduling process to prevent conflicts.  
  - Ensures safety and compliance with airline regulations.  

- Real-Time Updates  
  - Integrated APIs and data scraping keep flight information up-to-date.  

- Editable Flight Data  
  - Allows easy modification of schedules to accommodate dynamic changes.  

- Error Prevention**  
  - Minimizes human errors through advanced validation mechanisms.  

---

## Technologies Used  
- Frontend: JavaFX  
- Backend: SQL, APIs, Maven  
- APIs: ChatGPT API, data scraping APIs for real-time updates  
- Tools:
  - Server-based databases for robust data storage and retrieval.  
  - Java Maven for project build management.  

---

## Use Cases  
- Airline Companies: Manage their fleet and schedules efficiently.  
- Travel Agencies: Provide real-time updates to clients.  
- Individual Users: Check flight details or modify bookings with ease.
